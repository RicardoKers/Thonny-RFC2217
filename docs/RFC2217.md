# Uso do RFC 2217 no Thonny

1. Inicie o servidor RFC 2217 externo e o firmware MicroPython.
2. Execute `scripts/run_thonny.ps1` da raiz do workspace.
3. Abra **Tools → Options → Interpreter**.
4. Escolha **MicroPython (ESP32)** ou outro backend bare metal compatível.
5. Em **Connection**, selecione **RFC 2217 (TCP/IP)**.
6. Preencha o campo **RFC 2217 URL** e confirme com **OK**.

Exemplos:

```text
rfc2217://127.0.0.1:4000
rfc2217://localhost:4000
rfc2217://192.168.1.100:4000
```

O campo tem validação de esquema, host e porta TCP de 1 a 65535. Credenciais, caminho e fragmento são rejeitados. Parâmetros opcionais do PySerial na query são validados pelo próprio PySerial ao conectar. O cliente usa 115200 baud, como a serial local do backend atual. DTR e RTS seguem as configurações existentes da aba Advanced e são definidos antes de abrir a conexão; não é acrescentado pulso de reset. BREAK e o efeito físico dos sinais dependem do servidor.

A configuração efetiva é salva em `<backend>.port`, e `<backend>.rfc2217_url` lembra o último endpoint ao alternar para COM ou WebREPL. Os arquivos de configuração existentes continuam no formato usual do Thonny. No launcher deste workspace, ficam isolados em `.thonny-user/configuration.ini`.

O Shell aceita comandos Python e Ctrl+C. F5 executa o editor; Ctrl+D no Shell aciona o soft reset/fluxo de programa principal do backend existente. O navegador de arquivos e **Save as → MicroPython device** usam o mesmo protocolo de gerenciamento do Minny. Salvar em `main.py` ou `boot.py` tem o comportamento do firmware: não há garantia de persistência que o dispositivo ou simulador não ofereça.

## Falhas e reconexão

Se não conectar, confira host, porta e se outro cliente está usando o mesmo console. Uma porta TCP aberta precisa oferecer negociação RFC 2217; um serviço TCP comum não basta. Erros mostram o endpoint e a causa. Use **Stop/Restart backend** para reconectar após o servidor voltar, sem precisar reiniciar a IDE. Uma leitura ociosa por timeout não representa desconexão.

As escritas RFC são síncronas no PySerial e limitadas pelo timeout de socket dele. `outgoing_is_empty()` informa que não há escrita em andamento no Minny; não é confirmação de que o servidor ou dispositivo consumiu todos os bytes. Leituras têm timeout de 0,2 s para permitir encerramento e detecção de erro. Não há reconexão silenciosa durante execução nem repetição automática de comandos/arquivos parcialmente enviados.

No SimNodus de referência, Wi-Fi, Bluetooth e retenção após desligamento ainda não estão implementados. O transporte RFC 2217 funciona pelo TCP do computador e não requer Wi-Fi no ESP32 emulado. O exemplo `examples/blink_gpio4.py` controla GPIO4; o circuito deve ligar o LED a esse pino.
